      users are removed when that user is deleted. Use service accounts for anything running in
      production.

      cites ['DOC-DEPLOY-002#c01']

      cites ['DOC-DEPLOY-002#c01']
  --- DOC-DEPLOY-002#c01 | Rolling back a failed release / Resolution
      ## Resolution  1. Open the revisions page for the service and identify the last revision that
      was healthy. 2. Select roll back on that revision. Traffic moves within roughly thirty seconds
      and no rebuild takes place. 3. If the release included a database migration, roll the
      migration back before the service, or the older code will encounter a schema it does not
      expect. 4. Record the incident and the reason for the rollback before deploying a fix, while
      the detail is still fresh.  ## Notes  Rollback restores the container image and its
      configuration together. It does not restore data.
