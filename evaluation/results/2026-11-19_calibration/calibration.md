## 5. Threshold

**Chosen threshold: 0.95.**

**Trade-off.** Raising the threshold moves tickets from automatic answers to drafts for an agent: fewer wrong-intent answers, more agent work. Lowering it automates more and risks answering on a wrong intent. The table shows the cost at each step. Intent errors are only one source of wrong answers: tickets the docs cannot answer still pass this threshold (see 'Auto, expected auto_respond'), so the end-to-end 90% check (FR-11, revised) runs after Generate (5.8).
